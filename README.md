# Geldjacht 2M

Speurspel economie 2 mavo: hoofdstuk 2 Jij en je geld (2.1 t/m 2.4).

- `mc-h2.js`: meerkeuzevragen (makkelijk = set van 3, alle drie goed = 1 goede vraag)
- `open-h2.js`: open a/b-vragen (moeilijk), nagekeken door de AI (stand `mavo2`)
- `reken.js`: rekengeneratoren met nieuwe getallen (omrekenen week/maand/jaar, begroting, rente, kosten van een lening, eigen risico en premie)
- Doel per groep: 8 makkelijk, 3 moeilijk, 3 reken; na elke 4 goede vragen een fotokaartje en een pestkaart
- Nieuwe pestkaart "Eigen risico" (codes met een B): de gepeste groep levert 1 goede makkelijke vraag in
- `docent.html`: stand, nieuwe ronde, winnaars (pincode) · `bord.html`: scorebord voor het digibord
- Worker: `economie-2m-spel` (zelfde kaartcodes en QR-plekken als de Geldjacht en Fabrieksjacht)
